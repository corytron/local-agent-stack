# Heronsgate Lab operations handbook

Heronsgate Lab is a fictional organisation. This document is sample data for the retrieval suite
of the local-agent-stack evaluations; none of it describes a real place.

## Maintenance window

Planned maintenance happens on the second Tuesday of every month, from 02:00 to 04:00 UTC.
Changes outside the window need the approval of the duty lead.

## Change freeze

No changes are deployed between 15 December and 5 January, except security fixes.

## On-call

The on-call rotation changes every Monday at 09:30 local time. The escalation code word for a
site-wide outage is KESTREL-27.

## Contacts

The duty lead is reachable at duty-lead@example.com. The facilities desk answers on weekdays from
08:00 to 17:00.
