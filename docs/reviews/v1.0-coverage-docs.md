# v1.0 coverage review: design and research notes against the deployment guide

Reviewer Y, 2026-11-15, read-only. Rule audited: CLAUDE.md "The guide is self-contained" and
`docs/guide-style.md`. Inputs: `docs/stack-design.md`, `docs/research-contract.md`, and the
Summary, Recommendation, Details, "Fit with Claude Code features" and "Open questions" sections of
`docs/research/a-*.md` to `f-*.md`, checked against `guide/chapters/*.md` in the order of
`guide/guide.yaml`. The guide was built with `python3 tools/guide/build.py` (355 A4 pages, 18
chapters and appendices, 174 numbered tables, 1 figure); `python3 tools/check_links.py` reported
`links: 52 files, 354 links checked, 0 broken`. Ten pages were rendered at 60 dpi (15, 73, 101,
102, 140, 231, 302, 303, 304, 321), and every page was checked from the PDF's text layout for
text past the margins, mostly empty pages and headings or table captions at page bottoms.

Result: 1 blocker, 6 major, 21 minor. CLAUDE.md says a release waits until this list is empty,
so the minor items still need a fix or a recorded decision before `v1.0` is tagged.

Overlap with reviewer X (`docs/reviews/v1.0-coverage-repo.md`): Y-5 is X-1 (X rates it a
blocker), Y-6 includes X-2, and Y-28 is X-6.
