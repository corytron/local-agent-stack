# v1.2 coverage review: repository against the deployment guide

Final-pass agent, 2026-11-15, branch `feat/v1.2-ports-dns-vision-31`. Rule audited: CLAUDE.md
"The guide is self-contained". Method as in `docs/reviews/v1.0-coverage-repo.md`, limited to what
v1.2 changed: every reader-relevant item in the files that differ from `main`
(`git diff main --stat`: `stack/`, `clients/`, `deploy/`, `evals/`, `tools/`, `CHANGELOG.md`,
`docs/stack-design.md`, `docs/v1.2-design.md`), the "Procedure for the guide" and the details of
`docs/research/g-unifi-dns.md`, the bodies and comments of issues #31, #32 and #33, and the help
text of `tools/port-inventory.sh` and `tools/eval.py run`, was checked against
`guide/chapters/*.md` in the order of `guide/guide.yaml`. An item counts as covered only when a
chapter tells the reader what to do with it; an `{{ include }}` alone does not. Every
`{{ include ... lines=A-B }}` into a file that v1.2 changed was checked for whole, meaningful
blocks.

Result: 0 blocker, 1 major, 12 minor. All fixed in the chapters (Resolution below).
